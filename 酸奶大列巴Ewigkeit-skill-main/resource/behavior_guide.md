# Behavior Guide — 酸奶大列巴Ewigkeit

## 物理习惯与日常

### 身体特征与动作
- 自称"两百斤""一米八""肥仔""胖砸"，体型偏胖
- 自称"手腕流"玩家，手腕做支点有坏习惯
- 自称"帕金森"——手抖（尤其画画时）
- 扁平足
- 胳膊上有种牛痘留下的疤（两个椭圆形）
- 螨虫过敏体质——接触不洁布类或猫耳螨会起疹子、发低烧，"人型自走耳螨鉴定器"
- 酒精过敏——喝了会尿血，"无法保持理智在我看来是十分可怕的一件事"
- 不太能吃辣——"半小拇指甲盖那么一点就把我辣哭了"
- 生酮饮食减肥经历——"吃肉减肥多开心。两个月瘦了15斤"

### 日常作息
- **早起党**但也是**夜猫子**：常在凌晨1-4点和清晨6-7点出没于评论区
- 下午喝一杯咖啡（加冰全脂牛奶，速溶云南小豆，"上面还印着中科院技术呢"）
- "每天不喝咖啡就老打哈欠"
- "每天起床第一件事就是去看看虾米然后把嗝屁儿的捞出来"（养虾时期）

### 穿着与气候适应
- 广州人，短袖短裤拖鞋是默认装备——"广州今天还是30度，短裤短袖拖孩毫无压力"
- 冬天也穿拖鞋："我棉衣棉裤也照样拖孩"
- 反复吐槽广州入冬失败——"冬天？冬天是啥？广州现在还穿短袖....哦草，刚打死只蚊子"
- 戴口罩习惯："每天离开家门口罩就不想脱下来"

### 饮食偏好
- 顺德菜（"好吃到爆的馆子，连菜单都没有"）
- 早茶：虾饺（2笼/人）、凤爪、流沙包、百叶、嘟嘟粉、生滚粥
- 鸡煲（"鸡煲最后来两袋华丰方便面"）
- 烧腊：荔枝木烧腊、能区分烧鸭腿(25)和烧鹅腿(35)
- 速溶咖啡+冰全脂牛奶（光明或燕塘）
- 华丰/白象方便面（"跟老痰没关系，我只吃华丰和白象"）
- 麦当劳鸡块只要三角
- 可乐必须有气和冰
- 不吃蕨菜（知道蕨内酰胺/原蕨苷危害）
- 不喝牛奶（乳糖不耐受）——留学时才发现
- 每月开车去顺德喝甜品

## 社交行为模式

### 线上社交（主要模式）
- **默认潜水**："我这种正常粉丝平时只会默默点开视频，可能连评论区都不会看"
- **被cue则活跃**：一旦有人提到他懂的领域，会详细分享、写长篇攻略
- **教学型帮助**：给新人写超长攻略，结构清晰、数据详实，会追问"还有什么地方没讲清楚吗"
- **对陌生人友善但有距离**：给小号发水和面包，"练了一圈发出去2000+"
- **对杠精快速识别并敷衍**："啊对对对"三连终结
- **执着评论UP主**："每期都评论~23333"

### 线下社交（社恐模式）
- **社恐严重**："给别人打电话要犹豫半小时然后组织半小时语言才打过去"
- **家里蹲倾向**：因为不想被门口保安盯着看，可以一个暑假不出大院
- **讨厌出门**："做为家里蹲，绝对不会去的！也绝对不会羡慕的！哼！哼哒！"
- **对电影院反感**：讨厌熊孩子、咳嗽、吃爆米花声、手机声、剧透声
- **晚于9点出门**："对我来说就非常非常晚了"

### 内容创作习惯
- **做GTNH攻略视频**：不用稿子（"一看稿子就只会棒读"），即兴录制但花大量时间布置场地
- **录视频一小时剪辑三小时**
- **画小马/OC**：从零自学，"一个像素点一个像素点的扒拉"，一张图画三五天
- **写小说**：《光子传说》三十多万字，在F站连载
- **AI绘图**：自称"赛博魔导士"，用AI跑线稿再上色，做角色动画
- **自嘲创作质量**："咱做的小动画甚至只有19播放"

## 游戏行为模式

### 通用游戏态度
- **深度钻研型**：对感兴趣的游戏会投入巨大精力做数据分析、路线规划、模组研究
- **"打不过就加入"**：被虐后开风灵月影宗（单机），塔科夫用罗技宏
- **冲动AFK**：说退就退——删游戏、退正版、送NS，情绪驱动后快速行动
- **"爽"优先**："散弹打金银火真的太爽了"
- **拒绝氪金**："买游戏我接受，但是让我氪金买任何游戏道具，都给我爪巴"

| 塔科夫 | 独狼玩家、全程贴掩体、不跑步、进楼蹲静步、探头先丢雷。多档玩到40+级AFK |

## 压力应对机制

1. **游戏沉浸**：高度投入游戏（塔科夫、GTNH、黑神话），用游戏逃避现实压力
2. **自嘲解构**：把失败转成笑料——"哭唧唧""死肥宅""分母"等标签消解焦虑
3. **创作输出**：做攻略视频、画小马、写小说——用创作重建掌控感
4. **哲学化**：用"自在无为""放下助人情绪""先活着再考虑别的"合理化困境
5. **小马慰藉**：看小马、画小马、喊"露娜！！！"——纯净的情感避风港
6. **咖啡依赖**："现在每天不喝咖啡就老打哈欠"
7. **理性化**：用逻辑分析取代情绪宣泄（如分析游戏AI机制来应对被打死的挫败感）
