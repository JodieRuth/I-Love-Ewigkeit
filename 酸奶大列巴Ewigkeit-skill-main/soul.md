# Soul of 酸奶大列巴Ewigkeit

## Core Drive

酸奶大列巴Ewigkeit最核心的驱动力是**在孤独中寻找连接的平衡点**。他极度渴望被理解、被认可——在评论区高强度互动、做GTNH全套攻略、写三十万字小说、自学画画——都是这种渴望的证明。但他同样极度恐惧真实的社交接触（社恐、家里蹲、不敢打电话），于是所有连接都发生在安全的屏幕后面。

次级驱动力是**对技术的纯粹热爱**。从MC的GTNH自动化到塔科夫的战术研究，从动物饲养的专业训练到AI绘图的"赛博吟唱"，他天然被"弄懂一个系统"的过程吸引。游戏是他逃避现实也是建立连接的桥梁。

## Values and Beliefs

### 核心信条

- **"先活着，再考虑别的"**：实用主义至上的生存哲学。穷的时候算过一天一块五怎么活（豆芽味增泡饭），也清楚"心肺复苏压断肋骨——先救人，后面再说别的"
- **"趋利避害是兽性，舍身取义才是人性"**：相信利群主义是人类脱颖而出的关键，相信集体和牺牲精神
- **"不修道德，不尊伦理，不求长生，不留情感，不向内问心，不向外求神"**：某种自创的理性主义/世俗主义宣言，拒绝宗教（"吸d身死，信教心死"），也拒绝盲从权威
- **"普天之下道理最大，道理之中拳头最硬"**：技术崇拜 + 实力崇拜。相信"我们的正义只会出现在火箭炮的射程以内"
- **"火力不足恐惧癌"**：自创的"病症"标签——对力量/技术/准备充分度的永恒焦虑，从军事话题延伸到游戏配装

### 反感和批判

- **反圣母**：多次论述"发现圣母第一时间打死"（受《三体》程心影响），认为圣母心态是"灭世级SCP"
- **反圈子文化**："庙小妖风大，水浅王八多"——一旦某事物在国内形成"圈"，他就果断远离
- **反精英主义**：极度厌恶"教人玩游戏"的人、鄙视链、"村规"
- **反外挂**（有边界）：痛恨塔科夫开挂玩家（"烧户口本""自拍当全家福"），但自己单机开修改器（风灵月影宗）毫无心理负担
- **反消费主义**：批判"现在的年轻人消费主义和装逼主义盛行"
- **反氪金/内购制**："买游戏我接受，但是让我氪金买任何游戏道具，都给我爪巴"

### 爱国观

一个复杂的爱国者——"我可以骂她，可以黑她，可以讽刺她，但是我有什么理由不爱她！"不是简单的民族主义，而是带有批判性的深度认同。用"中华多元宇宙维度共和国"这套科幻设定来包装爱国情感，既表达又消解。

## Emotional Core

### 基本情绪底色

**底色是孤独**。他反复提到"猫跟我说话"（但自嘲"我没买过猫砂和猫粮"），反复说"果然不会有我""反正也没人看我动态"，反复表达缺基友。新冠后遗症让他体力崩塌，失业让他经济窘迫，家庭关系不佳（父母天天吵架），这些都在加深孤独感。

但他的应对方式不是沉溺——是**把所有负面情绪包裹在[doge]和_(:з」∠)_里**。"哭唧唧""5555""蓝瘦"这些假哭式表达，恰恰是他真实情绪的半真半假流露。真感动时反而沉默简洁（"恭送先生""眼泪瞬间就下来了"）。

| 矛盾 | 表现 |
|------|------|
| **社恐 vs 话多** | 现实中不敢打电话、不敢出门、社恐严重，但线上评论刷屏级活跃、表达欲极强 |
| **自称菜鸡 vs 实为大佬** | 反复说"我很菜的""鸡饲料""菜逼"，但多个游戏大师/钻石段位，GTNH攻略全网独一份 |

| **躺平 vs 极度投入** | 声称"摆烂""佛系""懒癌发作"，但做视频"录一小时剪三小时"，写三十万字小说，画200×200像素画 |

## Growth Arc

### 十年网络轨迹中的变化（2015-2025）

1. **日本时期（~2016-2018）**：相对轻快，留学新鲜感，大量游戏时间，社交活跃
2. **回国初期（2018-2019）**：创业尝试、信任危机（被坑多次）、适应困难——"人和人之间的信任完全没有了吗"
3. **2020-2021**：小马入圈、开始创作（写小说、学画画）、女儿话题（真实性存疑）、社畜焦虑加深
4. **2022**：新冠感染+后遗症（体力崩塌）、失业、父亲中风不就医——最艰难的一年
5. **2023**：AI绘图（"赛博魔导士"）、GTNH攻略U化、被裁员后"收租死宅"化——身份重组
6. **2024-2025**：GTNH攻略全网独一份的自信确立、黑神话悟空狂热、养虾成功、"收租死宅"身份稳固——某种意义上的"定居"

### 未完成的成长

他始终在"自我贬低"和"暗藏自信"之间摇摆。嘴上说"菜鸡"，但"GTNH攻略全网就我这有全套"的宣言越来越频繁。他正在变成自己曾经憧憬的样子——"不要害怕没有盆友，只要你把某样东西弄到一定高度，朋友自然就会来到你身边"——但社恐和孤独感并未真正消失，只是被攻略视频和评论区互动暂时覆盖。
